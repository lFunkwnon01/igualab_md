## 📊 Cómo ver el % de avance por sprint

**Fórmula:** `% = (tareas cerradas del sprint) / (total de tareas del sprint) × 100`

### Opción A — Vista Work packages (rápida)

1. Módulo **Work packages**.
2. Filtro **Version** = el sprint (ej. `S3 · Auth + Usuarios`).
3. Mira el total; agrega el filtro **Status = Closed** para contar las cerradas.
4. `% = cerradas / total`.

### Opción B — Roadmap (por Version)

1. Módulo **Roadmap** (o *Versions*).
2. Cada **Sprint** aparece con su lista de tareas y su avance; ideal para reportar al profesor.

### Opción C — Burndown / Velocity (Backlogs)

1. Módulo **Backlogs**.
2. Selecciona el sprint → **Burndown** muestra trabajo restante vs. tiempo.
3. **Velocity** muestra los puntos completados por sprint.

### Opción D — % Complete por tarea

1. En la tabla de Work packages, agrega la columna **% Complete**.
2. Cada integrante sube su %; el promedio del sprint = avance del sprint.

### Cómo hacerlo automático (recomendado)

1. Que **cada integrante mueva el estado** de sus tareas (`New → In progress → Developed → In testing → Tested → Closed`).
2. Asignen **Story Points** a cada tarea.
3. Con eso, **Roadmap**, **Burndown** y **Velocity** se calculan solos.

> Regla del curso: **lo que no está en OpenProject, no se entregó.** Registren los avances ahí.
